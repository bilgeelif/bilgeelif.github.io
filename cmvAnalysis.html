CMV Detection Module

AI-Powered Cytomegalovirus Detection in IHC Images

Computer Vision Deep Learning Medical Imaging IHC Analysis CMV Detection

Developed an AI-powered decision support algorithm for the detection of Cytomegalovirus (CMV) in immunohistochemical stained images. This module is now ready to be used with the Sectra PACS system, offering a comprehensive solution for the detection of cells with CMV inclusions.

Cases uploaded to the Sectra IDS7 workstation can be navigated via the home page. Selecting a case opens a new window to navigate through all glass images belonging to the selected case. A Disun icon sends the CMV-labelled image to the CMV detection module. The software processes the CMV-tagged image and marks each detected CMV nucleus in red for visibility.

Pathologists simply need to ensure the slide label includes 'CMV' or 'cytomegalovirus'; the software handles all subsequent steps automatically.
