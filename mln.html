Project Overview

The Mediasten project presents a unified CT-based framework for comprehensive mediastinal lymph node (MLN) analysis, addressing three critical clinical tasks: automated segmentation/detection, precise IASLC station mapping across 16 classes, and malignancy classification. This research addresses significant limitations in existing public datasets and provides a clinically validated approach to automated lymph node assessment.

The project utilized 69 cases from histopathologically confirmed lung cancer patients, with manual segmentation and labeling of 1,210 lymph nodes across stations 1-11 according to IASLC guidelines. The framework demonstrates expert-level consistency, achieving performance comparable to interobserver agreement among radiologists.

Technical Implementation

The system architecture employs the PARIETAL model as backbone network—a patch-based residual 3D U-Net with volumetric patches of size [32, 128, 128]. The framework incorporates three distinct but integrated components: segmentation using custom preprocessing and augmentation, station classification via handcrafted spatial-anatomical features, and malignancy prediction combining radiomics with station-specific features.

Three-Stage Pipeline Architecture:

  • Segmentation Module: PARIETAL 3D U-Net with mediastinal windowing and advanced data augmentation
  • Station Classification: 333 handcrafted spatial-anatomical features with Random Forest classifier
  • Malignancy Prediction: 854 radiomics features + 333 station-specific features with ANOVA selection
  • Clinical Validation: Comprehensive intra- and inter-observer variability studies
  • Multi-modal Features: Integration of tumor location and ipsilateral indicators
